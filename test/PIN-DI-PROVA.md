# PIN della copia di prova

Valgono solo per la copia di prova in `test/` (database finto nel browser). Non sono i PIN veri.

## Serata simulata (`serata.html`)
La serata crea tutto da sola, con questi PIN:

| Chi | PIN |
|---|---|
| Master (Don Paolo) | 111111 |
| Cassa 1 … Cassa 4 | 2001 … 2004 |
| Capo cucina | 3000 |
| Cuoco Primo / Fritto / Secondo, Cuoca Dolci | 3001 / 3002 / 3003 / 3004 |
| Uscita | 6000 |
| Bar | 4000 |
| Capo camerieri | 5000 |

I camerieri entrano col codice QR che la serata genera.

## Prova a mano (`index.html`)
Al primo avvio crea tu il master con un PIN a piacere: il database finto parte vuoto. Ogni scheda del browser è un telefono diverso.
